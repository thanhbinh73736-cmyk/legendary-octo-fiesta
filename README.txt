CHRONICA – BẢN WEB APP PWA

CÁCH CHẠY THỬ
1. Giải nén chronica.zip.
2. Đưa toàn bộ thư mục lên dịch vụ hosting tĩnh có HTTPS (ví dụ GitHub Pages hoặc Netlify).
3. Mở đường dẫn website trên Chrome Android.
4. Chọn menu Chrome > Cài đặt ứng dụng / Thêm vào màn hình chính.

LƯU Ý
- Đây là bản MVP chạy trên trình duyệt, chưa phải ứng dụng Android APK.
- Chế độ luyện tập có thể chọn cấu hình. Ngân hàng câu hỏi hiện tại là dữ liệu mẫu, tập trung vào lịch sử thế giới thời cận đại.
- Chế độ mô phỏng thi dùng 24 câu nhiều lựa chọn + 4 câu đúng-sai. Điểm phần đúng-sai trong bản mẫu là cách tính giản lược; cần hoàn thiện theo quy tắc chấm từng ý chính thức trước khi dùng làm đề chuẩn.
- Nhạc hiện là âm nền tổng hợp đơn giản, chưa phải bản piano thu âm. Trình duyệt yêu cầu người dùng chủ động bật âm thanh.
- Cần internet để tải font và ảnh nền từ nguồn ngoài; nội dung app cơ bản được cache sau lần mở đầu.
